# 🎒 Achados & Perdidos Escolar (PWA)

Aplicação web progressiva desenvolvida como atividade da disciplina, aplicando o paradigma de **Desenvolvimento Orientado à Inteligência Artificial (Agentic Coding)**.

## 🧠 Conceitos Pesquisados
- **Desenvolvimento Orientado à IA:** Paradigma onde o desenvolvedor atua como arquiteto, engenheiro de requisitos e revisor, utilizando agentes especializados (como projetos customizados e agentes CLI no OpenCode) para planejar, gerar, testar e refatorar código de forma iterativa.
- **PWA (Progressive Web App):** Aplicações web que utilizam `Service Workers` e `Web App Manifest` para oferecer experiência semelhante a aplicativos nativos, incluindo instalação na tela inicial e funcionamento offline.

## 🤖 Comparativo de Modelos de IA Testados
Durante o desenvolvimento, foram comparados dois modelos:
1. **Modelo A (ex: GPT-4o / Claude Sonnet):** Destacou-se na estruturação semântica do HTML e na escrita limpa da lógica de filtros e `localStorage`, entregando código funcional na primeira iteração.
2. **Modelo B (ex: Gemini Pro / Modelo Open-Source via OpenCode):** Foi excelente na revisão de responsividade CSS e na configuração do cache offline no `sw.js`, identificando ajustes necessários nos caminhos relativos para funcionar no GitHub Pages.

## 🚀 Como Executar
1. Clone este repositório.
2. Abra com uma extensão como **Live Server** (VS Code) ou acesse diretamente o link publicado.
3. No navegador (Chrome/Edge/Safari), clique no ícone de **Instalar Aplicativo** na barra de endereços.
